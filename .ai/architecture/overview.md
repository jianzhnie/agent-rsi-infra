# 仓库结构

共享规范放在 `.ai/`，共享任务流程放在 `.agents/skills/`。工具目录只承接该客户端的入口和专用能力。

Claude 资源由旧 `agent/` 迁入 `.claude/`；通用规则与技能拆到共享目录。完整设置采用 `settings.example.json` 命名，避免迁移后自动启用；MCP 配置已移除。

测试维护在 `tests/`，与可部署资源分开。调研资料在 `docs/research/`，实施方案与部署方式在 `docs/`。

本仓库不提供训练或推理实现。领域指南描述目标项目中的检查方向；增加具体 Skills 前，应先获得真实仓库、可运行命令与验证条件。
